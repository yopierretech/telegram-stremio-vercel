# Telegram → Stremio / Nuvio (Vercel)

אתר שבו כל משתמש מתחבר לחשבון הטלגרם **שלו** (טלפון + קוד, ו-2FA רק אם מוגדר לו) ומקבל כתובת `manifest.json` להדבקה ב-Stremio / Nuvio.
אין מסד נתונים: ה-session מוצפן (AES-256-GCM) ומוטמע בכתובת.
אם מוגדרים `TG_API_ID` / `TG_API_HASH` באתר, המשתמשים לא צריכים להכניס api כלל. אם לא, הטופס מבקש מכל משתמש api_id / api_hash משלו.

## פריסה

1. העלה ל-GitHub וייבא ב-Vercel (או `npx vercel`).
2. Environment Variables:

| משתנה | תיאור |
|---|---|
| `SECRET_KEY` | **חובה.** מחרוזת אקראית ארוכה (`openssl rand -hex 32`). אל תשנה אחרי שיש משתמשים, כל הכתובות יפסיקו לעבוד |
| `SITE_PASSWORD` | אופציונלי. אם מוגדר, האתר מבקש סיסמה (שימוש פרטי) |
| `TG_API_ID`, `TG_API_HASH` | מ-https://my.telegram.org/apps. כשהם מוגדרים, המשתמשים מזינים רק טלפון וקוד |
| `MSG_FILTER` | `document` אם קבצי mkv לא מופיעים |
| `MAX_SEARCH_CHANNELS` | ברירת מחדל 15 |

## לפני פרסום לציבור

- **אמון:** השרת שלך מטפל בקוד ובסיסמת ה-2FA של אחרים, וב-`SECRET_KEY` אפשר לפענח כל כתובת. הגן על ה-env ב-Vercel, הפעל 2FA לחשבון Vercel/GitHub, ואל תדפיס טוקנים ללוגים.
- **Vercel:** תוכנית Hobby לשימוש אישי לא מסחרי, והזרמת וידאו לרבים תחרוג ממכסת ה-bandwidth. שירות ציבורי דורש בדרך כלל Pro או אירוח אחר (Render / Railway / VPS).
- **משפטי:** הוסף דף תנאי שימוש ופרטיות, ודף/מייל להסרת תוכן. בדוק מול עורך דין לפני פרסום.
- **api משותף:** כל המשתמשים עוברים דרך ה-api_id שלך. ריבוי חשבונות וכניסות משרת עלולים לגרום לטלגרם להגביל או לחסום אותו, ואז האתר כולו יפסיק לעבוד.
- **טלגרם:** כניסות מכתובות IP של שרת יכולות להפעיל התראות אבטחה בחשבון המשתמש. ציין את זה באתר.
- קבצי mkv מסומנים `notWebReady` (מתאים ל-Stremio desktop/mobile ול-Nuvio, לא ל-Stremio Web).
